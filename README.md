# zyuzka/tap

Homebrew tap for [Hats](https://github.com/zyuzka/hats), a menu-bar app that switches the
logged-in Claude Code account without a relogin.

```sh
brew install zyuzka/tap/hats
```

If Homebrew refuses to load a cask from an untrusted tap, trust this one first:
`brew trust zyuzka/tap`.

Hats updates itself after that (Sparkle), so the cask is marked `auto_updates`.
Apple silicon only for now.
